# UI 截图筛选结果

> 从 55 张 Google Stitch 生成的截图中，按页面类型筛选最佳版本。
> 每个页面推荐 1 个最佳基底 + 1 个备选，标注优缺点。

---

## 筛选标准

| 维度 | 权重 | 说明 |
|------|------|------|
| 风格匹配 | 35% | 深空黑底 + 青色主色 + 科幻感 |
| 布局质量 | 25% | 信息层级清晰、不拥挤不空旷 |
| 内容完整 | 20% | 包含提示词要求的所有数据区域 |
| 视觉吸引力 | 10% | 发光、毛玻璃、动效潜力 |
| 可实现性 | 10% | 用 Next.js + Tailwind 能否还原 |
