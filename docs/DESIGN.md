## 一、设计系统

### 1.1 设计理念

NovaStar 采用**未来科幻**视觉风格，灵感来源于 Tron、Cyberpunk 和 Blade Runner。核心设计原则：

- **信息优先**：数据可视化是核心，所有装饰服务于信息传达
- **动态感知**：页面是"活"的，数据实时流动，界面持续呼吸
- **深度层次**：通过毛玻璃、发光边框、粒子背景创造空间感
- **交互沉浸**：每个操作都有视觉反馈，让用户感觉在操控未来科技

### 1.3 字体规范

#### 标题字体：Orbitron
几何感、未来感的无衬线字体，用于标题和品牌标识。

| 级别 | 字号 | 行高 | 字重 | 用途 |
|------|------|------|------|------|
| H1 | `clamp(2rem, 1.5rem + 2vw, 3rem)` | 1.2 | 700 | 页面标题 |
| H2 | `clamp(1.5rem, 1.25rem + 1.5vw, 2.25rem)` | 1.3 | 600 | 区域标题 |
| H3 | `clamp(1.25rem, 1rem + 1vw, 1.75rem)` | 1.4 | 600 | 卡片标题 |
| H4 | `1.125rem` | 1.4 | 500 | 小标题 |

#### 正文字体：Inter
高可读性的无衬线字体，用于正文和界面文字。

| 级别 | 字号 | 行高 | 字重 | 用途 |
|------|------|------|------|------|
| Body | `1rem` (16px) | 1.6 | 400 | 正文内容 |
| Body Small | `0.875rem` (14px) | 1.5 | 400 | 辅助文字 |
| Caption | `0.75rem` (12px) | 1.4 | 400 | 标签、时间戳 |
| Overline | `0.6875rem` (11px) | 1.4 | 500 | 大写标签 |

#### 等宽字体：JetBrains Mono
用于代码、数据、终端风格显示。

| 级别 | 字号 | 行高 | 字重 | 用途 |
|------|------|------|------|------|
| Code | `0.875rem` (14px) | 1.5 | 400 | 代码块 |
| Data | `1.5rem` (24px) | 1.2 | 500 | 数字显示 |
| Data Small | `0.875rem` (14px) | 1.4 | 500 | 数据标签 |
| Mono | `0.75rem` (12px) | 1.4 | 400 | 终端输出 |

#### Widget 网格系统

采用 CSS Grid 实现响应式 Widget 布局：

- **桌面端**：3 列网格，Widget 可跨列
- **平板端**：2 列网格
- **手机端**：1 列堆叠

Widget 尺寸单位：
- Small：1x1（最小）
- Medium：1x2 或 2x1
- Large：2x2
- Full：3x1（全宽）

#### 3D 地球交互设计

- **旋转**：鼠标拖拽旋转，触屏手势支持
- **缩放**：滚轮/双指缩放
- **悬停**：数据点悬停显示详情卡片
- **点击**：点击数据点显示贡献者详情
- **数据点**：脉冲动画，大小表示贡献量
- **连线**：贡献者之间的协作关系线
- **后处理**：泛光（Bloom）、色差（Chromatic Aberration）

#### 底部统计卡片

每个卡片包含：
- 图标（自定义 SVG）
- 数值（AnimatedCounter，加载时从 0 计数到目标值）
- 标签（JetBrains Mono 字体）
- 趋势指示器（上升/下降箭头 + 百分比）

### 3.1 按钮（Button）

#### 变体

| 变体 | 背景 | 文字 | 边框 | 用途 |
|------|------|------|------|------|
| Primary | 主色 | 深色 | 无 | 主要操作 |
| Secondary | 透明 | 主色 | 主色边框 | 次要操作 |
| Ghost | 透明 | 前景色 | 无 | 文本操作 |
| Danger | 透明 | 错误色 | 错误色边框 | 危险操作 |
| Glow | 主色 | 深色 | 无 + 发光 | 特殊强调 |

#### 尺寸

| 尺寸 | 高度 | 内边距 | 字号 | 圆角 |
|------|------|--------|------|------|
| Small | 32px | 12px 16px | 14px | 6px |
| Medium | 40px | 12px 20px | 14px | 8px |
| Large | 48px | 16px 24px | 16px | 12px |

#### 状态

| 状态 | 样式变化 |
|------|----------|
| Default | 基础样式 |
| Hover | 发光增强 + scale(1.02) |
| Active | scale(0.98) + 发光减弱 |
| Disabled | 透明度 0.5 + 禁止交互 |
| Loading | 显示旋转图标 + 禁止交互 |

## 四、图标系统

### 4.1 设计原则

- **全自定义 SVG**：每个图标单独设计，不依赖第三方图标库
- **风格自由**：不同图标可以有不同风格，但需保持整体协调
- **线条规范**：线条粗细 1.5px - 2px
- **尺寸规范**：16px / 20px / 24px / 32px 四种尺寸
- **颜色继承**：默认跟随文字颜色，可通过 fill/stroke 自定义

### 4.2 图标分类

#### 导航图标
- Logo（六边形 + 星星）
- 首页
- GitHub
- 天气
- 新闻
- 3D 可视化
- 设置

#### 操作图标
- 搜索
- 通知
- 主题切换（月亮/太阳）
- 用户头像
- 添加
- 编辑
- 删除
- 关闭
- 全屏
- 刷新

#### 数据图标
- Star（星星）
- Fork（分支）
- Commit（提交）
- PR（合并）
- Issue（问题）
- 贡献者
- 语言

#### 状态图标
- 在线（绿色圆点）
- 离线（灰色圆点）
- 加载中（旋转）
- 成功（对勾）
- 错误（叉号）
- 警告（三角）

### 4.3 图标动画

每个图标组件支持以下动画属性：

```typescript
interface IconProps {
  size?: 16 | 20 | 24 | 32;
  color?: string;
  animation?: 'none' | 'spin' | 'pulse' | 'scan' | 'flow';
  animationDuration?: string; // 默认 '1s'
  className?: string;
}
```

动画类型：
- **spin**：持续旋转（如加载图标）
- **pulse**：脉冲缩放（如通知图标）
- **scan**：左右扫描（如搜索图标）
- **flow**：数据流动效果（如 GitHub 图标）

```

    │
    ├─→ 服务端检测到变化
    │        │
    │        ├─→ 新数据存入缓存
    │        └─→ 推送 SSE 事件到前端
    │
    ├─→ 前端接收 SSE 事件
    │        │
    │        ├─→ 更新 SWR 缓存
    │        ├─→ 触发相关 Widget 重新渲染
    │        └─→ 更新底部状态栏（最后更新时间）
    │
    ├─→ Widget 数据更新
    │        │
    │        ├─→ 新旧数据对比
    │        │        │
    │        │        ├─→ 有变化 → 过渡动画
    │        │        │           │
    │        │        │           ├─→ 新项目：从右侧滑入
    │        │        │           ├─→ 移除项目：向左侧滑出
    │        │        │           └─→ 数值变化：计数动画
    │        │        │
    │        │        └─→ 无变化 → 跳过
    │        │
    │        └─→ 显示"新数据"指示器
    │                 │
    │                 └─→ 2秒后自动隐藏
    │
    └─→ 底部状态栏更新
             │
             ├─→ 更新时间：从 X 秒前 重置为 刚刚
             └─→ API 限流：更新剩余请求数
```

### 5.6 主题切换流程

```
用户点击主题切换按钮
    │
    ├─→ 切换主题变量
    │        │
    │        ├─→ 更新 CSS 自定义属性
    │        ├─→ 保存偏好到 localStorage
    │        └─→ 图标过渡动画（月亮 ↔ 太阳）
    │
    ├─→ 所有组件平滑过渡
    │        │
    │        ├─→ 背景色过渡（500ms）
    │        ├─→ 文字色过渡（300ms）
    │        ├─→ 边框/阴影过渡（300ms）
    │        └─→ 发光效果调整（300ms）
    │
    └─→ 完成切换
```

## 六、动效系统

### 6.1 动画时长规范

| 类型 | 时长 | 缓动函数 | 用途 |
|------|------|----------|------|
| 微交互 | 150-200ms | ease-out | 按钮悬停、切换 |
| 面板过渡 | 300-400ms | ease-in-out | 面板打开/关闭 |
| 页面过渡 | 500-600ms | cubic-bezier(0.22, 1, 0.36, 1) | 路由切换 |
| 数据脉冲 | 800-1200ms | ease-in-out infinite | 实时数据指示器 |
| 环境发光 | 2000-4000ms | ease-in-out infinite alternate | 背景效果 |
| 交错入场 | 50ms 延迟/项 | ease-out | 列表/网格项入场 |

### 6.2 缓动函数

```css
:root {
  --ease-default: cubic-bezier(0.4, 0, 0.2, 1);
  --ease-in: cubic-bezier(0.4, 0, 1, 1);
  --ease-out: cubic-bezier(0, 0, 0.2, 1);
  --ease-in-out: cubic-bezier(0.4, 0, 0.2, 1);
  --ease-bounce: cubic-bezier(0.34, 1.56, 0.64, 1);
  --ease-spring: cubic-bezier(0.22, 1, 0.36, 1);
}
```

#### 粒子效果（Particle Field）
使用 Canvas 或 CSS 实现轻量级粒子系统：

- 粒子数量：可配置，默认 50 个
- 粒子大小：1-3px
- 粒子颜色：主色（半透明）
- 运动：缓慢漂浮 + 随机方向
- 交互：鼠标靠近时粒子被推开

#### 脉冲效果（Pulse）
```css

}
```

### 6.4 性能优化

- **GPU 加速**：只动画 `transform` 和 `opacity`
- **CSS 动画优先**：重复效果用 CSS，复杂编排用 Framer Motion
- **减少重绘**：使用 `will-change` 提示浏览器
- **降低粒子数**：移动端默认减少粒子数量
- **尊重用户偏好**：`prefers-reduced-motion` 时禁用动画

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}
```
