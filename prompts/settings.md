# Google Stitch 提示词 — 系统设置页

> 本文件专门用于生成系统设置页的 UI。
> 其他页面的提示词在 stitch-prompts.md 中。

---

## 核心设计原则

### 1. 飞船控制面板风格
- 不是传统的白底设置页，是太空飞船的系统配置界面
- 每个设置项都有科技感的视觉反馈
- 滑块、按钮、输入框都有青色发光效果

### 2. 左右两栏布局
- 左侧：垂直导航菜单（外观设置、数据源、Widget、API 状态、系统信息）
- 右侧：对应的内容面板
- 不是传统的单列设置页

### 3. 状态可视化
- API 状态用圆形仪表盘展示（不是简单的列表）
- 数据源连接状态用脉冲发光圆点
- 在线/离线状态一目了然

---

## 使用技巧

### 生成时的额外指令
在 Stitch 提示词最前面加：
"重要：深色太空背景，飞船控制面板风格，所有开关和滑块有青色发光效果。标题必须使用 Orbitron 字体。所有 UI 文字使用中文。"

### 如果生成不满意
1. 太像普通设置页 → 加"这是太空飞船的系统控制面板，不是普通网站设置页"
2. 布局太传统 → 加"左右两栏布局：左侧垂直导航 + 右侧内容区"
3. 滑块没发光 → 加"滑块填充部分有青色渐变发光，圆点有外发光"
4. 缺少状态可视化 → 加"API 状态用圆形仪表盘展示，数据源用脉冲发光圆点"
5. 颜色不对 → 加"背景色必须是 #0A0E1A，面板背景 rgba(17,24,39,0.85)"
