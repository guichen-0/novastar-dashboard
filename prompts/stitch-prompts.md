## 提示词 1：仪表盘主页（地球为中心的太空指挥台）

```
设计一个以地球为绝对视觉中心的太空科幻仪表盘。

=== 核心原则（最重要）===
整个页面的中心是一个大型地球。所有其他元素（导航、面板、数据卡片）都分布在地球周围。
地球占页面面积的 35-40%，是最大的视觉元素。页面不是"网格布局"，而是"地球+环绕元素"的辐射式布局。

=== 页面布局（辐射式，地球居中）===
用文字描述这个布局的空间关系：

```

│  │ 面板 A  │         🌍🌍🌍🌍              │ 面板 D  │      │

│  │ 终端    │         🌍🌍🌍🌍              │         │      │
│  └─────────┘      (大型3D地球)              └─────────┘      │
│                       │                                     │
│  ┌─────────┐    [数据卫星环绕]        ┌─────────┐           │
│  │ 面板 B  │  🛰 🌧 🔥 🌐 ☀️ 💻 🚀 📰  │ 面板 E  │           │

=== 地球（页面绝对中心，最大元素）===
页面正中央是一个大型 3D 地球，这是整个页面的视觉锚点：

地球外观：
- 青色（#00E5FF）线框球体，经纬线网格清晰可见
- 球体缓慢自转（CSS 3D 动画，Y轴旋转，约30秒一圈）
- 球体边缘有青色光晕（box-shadow: 0 0 60px rgba(0,229,255,0.3)）
- 球体是半透明的（opacity: 0.85），可以看到后面的星空背景
- 球体有微妙的光泽感（radial-gradient 模拟光照）

地球表面数据层：
- 发光数据点：全球主要城市位置，用小圆点表示，有脉冲发光动画
- 弧形连线：城市之间有半透明弧线连接，体现"世界互联"
- 连线光点：弧线上有小光点在流动，模拟数据传输
- 地震标记：洋红色（#FF0090）脉冲圆圈
- 火灾热点：红色闪烁点
- 降雨层：半透明蓝绿色热力图层

地球交互：
- 用户可以鼠标拖拽旋转地球
- 悬停地球表面的数据点 → 显示信息浮窗（城市名 + 数据）
- 点击地球上的数据标记 → 展开详情面板

=== 数据卫星系统（环绕地球轨道）===
地球周围有 8 颗数据卫星，沿圆形轨道缓慢公转：

卫星排列（从地球向外看，顺时针分布）：
- 位置1（12点方向）：🌧 降雨卫星 — 半透明球体内有雨滴粒子下落
- 位置2（1:30方向）：🌐 地震卫星 — 半透明球体内有波纹扩散
- 位置3（3点方向）：🔥 火灾卫星 — 半透明球体内有火焰跳动
- 位置4（4:30方向）：🛰 卫星追踪 — 半透明球体内有轨道环旋转
- 位置5（6点方向）：☀️ 太空天气 — 半透明球体内有耀斑闪烁
- 位置6（7:30方向）：💻 GitHub — 半透明球体内有 `< />` 浮动
- 位置7（9点方向）：🚀 NASA — 半透明球体内有星辰闪烁
- 位置8（10:30方向）：📰 新闻 — 半透明球体内有文字滚动

卫星样式：
- 每颗卫星是一个直径 40-50px 的半透明发光球体
- 球体有青色边框 + 内部动态图标
- 卫星沿圆形轨道缓慢公转（约60秒一圈）
- 每颗卫星有一条微弱的虚线轨道圆环

卫星交互：
- 悬停卫星 → 卫星放大 1.5 倍 + 名称标签浮现（半透明毛玻璃标签，显示如"降雨监测"）
- 悬停时 → 地球上对应的数据层高亮，其他层变暗
- 点击卫星 → 跳转到对应的数据详情页

=== 左上角 — Logo 和主导航 ===
在页面左上角，一个小型悬浮面板：

### 在 Google Stitch 中使用提示词时：

1. **字体强制**：写 "标题必须使用 Orbitron 字体，不要用 Space Grotesk"
2. **颜色精确**：直接写 HEX 值 #00E5FF，不要只说"蓝色"
3. **中文强制**：明确写 "所有 UI 文字必须使用中文"
4. **地球元素**：每次都要提到 "背景有地球轮廓/线框"
5. **互联概念**：强调 "数据点之间有连线，体现世界互联"
6. **数据源预留**：明确列出要展示的数据源名称

### 如果生成不理想：

1. 在最前面加："重要：严格使用以下颜色值..."
2. 加负面提示："不要使用 Space Grotesk 字体，不要使用浅色背景，不要使用英文 UI"
