# Google Stitch 提示词 — 全球发展指标页

> 本文件专门用于生成全球发展指标页的 UI。
> 其他页面的提示词在 stitch-prompts.md 中。

---

## 核心设计原则

### 1. 数据要"活"起来
- 不是静态表格，每个数字都有动态效果
- 统计卡片有迷你图表（折线图、柱状图、环形图）
- 数字加载时有从 0 计数到目标值的动画

### 2. 太空科技感不能丢
- 深空黑背景 + 星空粒子 + 地球线框装饰
- 数据有青色发光效果
- 图表线条有发光描边

### 3. 信息密度要高
- 4 个统计卡片 + 2 个图表 + 1 个表格 = 7 个数据区域
- 每个区域都有具体数字和可视化

---

## 使用技巧

### 生成时的额外指令
在 Stitch 提示词最前面加：
"重要：深色太空背景，地球线框装饰，所有数据有青色发光效果。标题必须使用 Orbitron 字体。所有 UI 文字使用中文。"

### 如果生成不满意
1. 背景太亮 → 加"背景色必须是 #0A0E1A 深空黑，不要浅色背景"
2. 没有科幻感 → 加"页面右上角有极淡的青色地球线框装饰，背景有星空粒子"
3. 数字不发光 → 加"所有大数字使用青色（#00E5FF）发光效果"
4. 图表太普通 → 加"折线图线条有青色发光，柱状图有渐变效果"
5. 缺少动态 → 加"数字加载时从 0 计数到目标值，图表有绘制动画"

=== 背景效果（必须有，让页面不"干"）===

整个页面的背景：
- 基底：#0A0E1A 深空黑
- 星空粒子：约150个微小白色光点（1-3px），缓慢漂浮
- 地球线框：页面右上角有一个极淡的青色地球线框（opacity 0.05-0.08），作为装饰
- 网格线：极微弱的青色网格（opacity约0.03），间距50px
- 数据流光线：从页面左侧到右侧有几条极淡的青色光线在流动，模拟数据传输

=== 上方 — 四个大型统计卡片（横排，大小不完全相同）===

- 趋势：↑3.2%（绿色，带小箭头）
- 迷你折线图：最近5年GDP趋势（青色发光线条，3个数据点）
- 卡片边框：青色发光
- 背景：毛玻璃 + 极淡的地球经纬线纹理

卡片 2 — "全球人口"（中等）：
- 顶部：👥 图标
- 大数字："81.2 亿"（Orbitron 字体，青色发光）
- 趋势：↑0.9%（绿色）
- 迷你柱状图：近5年人口增长（3个青色柱体）

卡片 3 — "互联网覆盖率"（中等）：
- 顶部：🌐 图标
- 大数字："67.4%"（Orbitron 字体，青色发光）
- 趋势：↑2.1%（绿色）
- 迷你环形图：已覆盖 67.4% vs 未覆盖 32.6%

卡片 4 — "可再生能源占比"（最右边，稍小）：
- 顶部：⚡ 图标
- 大数字："32.8%"（Orbitron 字体，洋红色 #FF0090 发光）
- 趋势：↑5.4%（绿色，增长最快所以用洋红强调）
- 迷你环形图：可再生 32.8% vs 传统 67.2%

卡片通用样式：
- 背景：rgba(17, 24, 39, 0.85) + blur(16px)
- 边框：1px solid rgba(0, 229, 255, 0.15)
- 圆角：12px
- 悬停：边框发光增强 + 卡片上浮 2px

=== 中间 — 两个图表（左右两栏）===
